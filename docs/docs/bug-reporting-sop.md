# Bug Reporting SOP — AthletIQ

## Purpose
This document explains the process for identifying, tracking, and resolving bugs within the AthletIQ platform.

---

## Step 1: Identify the Bug
- Confirm the issue exists
- Record what happened
- Note affected feature

---

## Step 2: Create GitHub Issue
- Add clear title
- Add detailed description
- Include screenshots if necessary

---

## Step 3: Assign Priority
- High = critical problem
- Medium = affects usability
- Low = minor issue

---

## Step 4: Update Workflow Status
- Backlog
- In Progress
- Review
- Done

---

## Step 5: Track Progress
- Add comments
- Update status regularly
